# GitHub Actions Desktop

## 使用方法

1. このリポジトリをFork（フォーク）する
2. <img width="621" height="234" alt="image" src="https://github.com/user-attachments/assets/2ba5caa1-955b-46f4-b6fd-9650e687ca4d" />
3. [Desktopワークフロー](../../actions/workflows/desktop.yml)を開く
4. ワークフロー「Chrome」を実行する
5. 表示されたDesktopのURLを開く
6. `curl x` または `x/` をアドレスバーに入力してセッションを停止する
